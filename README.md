## Projects

### Uzi's Map Editor *(private)*
A 3D map editor for OSRS-based game servers, written in Kotlin with an OpenGL renderer. It extends an open-source editor with a lot of new tooling:
- Terrain sculpting, tile painting with texture swatches, and 12 overlay shapes with live previews
- Object picker with rendered thumbnails, drag-to-place and drag-to-delete, and multi-floor editing
- Area copy/paste across floors, prefab files, and find & replace
- A clickable world map drawn straight from the game cache
- One-click deploy to a live Linux server over SSH (backup, swap, restart, rollback)
- Portable packaging with a bundled Java runtime

*Private repo. Demo available on request.*
